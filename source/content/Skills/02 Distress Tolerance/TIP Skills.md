## Progressive/Prepared Muscle Relaxation (PMR)
- Sit or lie down in a comfortable position
- Usually starting with the feet, tense muscle in one set of muscles for ~5 seconds
- Slowly relax these muscles, optionally as you say "relax"
- Go up the body and repeat the same steps
- Repeat entire process until sated
